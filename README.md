# Портфолио — mililil-ka

Личный сайт-портфолио: React + Vite + Tailwind CSS.
Включает AI-чат-бота (через ProxyAPI), галерею AI-генераций и проекты.

## Стек

- React 18
- Vite
- Tailwind CSS
- Framer Motion (в планах)
- ProxyAPI (OpenAI / Claude / Gemini через один ключ)

## Запуск локально

```bash
npm install
npm run dev
